# **App Name**: Nirmaan Edu PWA

## Core Features:

- User Authentication: Secure login for students with session management.
- Personalized Dashboard: Dynamic display of 'What’s New', pending tasks, and leaderboard standings.
- Interactive Case Studies: Listing and detailed views with multi-format assessment support (text, MCQs, audio, video, file uploads).
- Course Management: Enrollment and progress tracking with chapter-based content (PDFs, videos, quizzes).
- Gamification System: Points, badges, leaderboards, and streaks to motivate and engage students.
- Profile Management: User profile, settings, achievements, and help/support integration.
- Smart Task Suggestions: AI tool that analyzes student's past performance and suggests relevant learning activities to enhance understanding.

## Style Guidelines:

- Primary color: Orange (#FF4D01) to reflect the brand's identity and energy.
- Background: Light Grey (#E7E7E8) for a clean and modern learning environment.
- Headings font: 'Nunito' (sans-serif) for modern, readable headlines.
- Body text font: 'Nunito' (sans-serif) for optimal readability across devices.
- Consistent use of Heroicons or Lucide React for a uniform and intuitive user experience.
- Subtle animations and micro-interactions for enhanced user engagement.
